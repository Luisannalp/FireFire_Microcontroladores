# Diseño 3D

Esta carpeta contiene los modelos y planos tridimensionales del proyecto **FireFire**.

## Contenido previsto

- Modelos CAD de piezas, ensambles y del chasis.
- Archivos fuente editables (`.f3d`, `.step`, `.stp`, `.ipt`, `.sldprt`, `.sldasm`).
- Exportaciones para impresión 3D (`.stl`, `.3mf`) y para fabricación.
- Renders y capturas de referencia del diseño.

## Convenciones

- Mantener el archivo fuente editable junto a sus exportaciones.
- Nombrar los archivos con el formato `pieza_version` (por ejemplo, `soporte_sensor_v2.step`).
- Evitar archivos temporales o autoguardados de los programas CAD.
