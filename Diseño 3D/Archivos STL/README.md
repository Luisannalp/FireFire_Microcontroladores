# Archivos STL

Exportaciones en formato STL de los modelos CAD del proyecto **FireFire**, listas para impresión 3D o corte.

## Convenciones

- Generar los STL a partir del archivo fuente de `Archivos CAD/`.
- Mantener el mismo nombre base que el modelo original (por ejemplo, `wheel holder 1.stl`).
- Exportar con resolución media/alta y en milímetros.
- No modificar los STL a mano: si cambia el diseño, se vuelve a exportar desde el CAD.
