# Firmware

Esta carpeta contiene el código fuente del sistema embebido del proyecto **FireFire**.

## Contenido previsto

- Código del microcontrolador (drivers, lógica de control y comunicaciones).
- Proyectos de compilación (por ejemplo, PlatformIO, STM32CubeIDE, MPLAB X o Arduino).
- Librerías y dependencias de terceros utilizadas.
- Scripts de carga (flashing) y pruebas.

## Convenciones

- Un subdirectorio por componente o placa cuando el proyecto lo requiera.
- No subir archivos binarios generados en la compilación (`.hex`, `.bin`, `.elf`, `.o`), salvo que sean entregables de una versión.
- Documentar en este README cualquier cambio relevante en la estructura del código.
