# Documentación

Esta carpeta contiene la documentación formal del proyecto **FireFire**.

## Contenido

- `Documento requisitos.docx`: documento de especificación de requisitos del proyecto.

## Contenido previsto

- Requisitos funcionales y no funcionales.
- Diagramas de arquitectura, bloques y flujo.
- Manuales de usuario, instalación y mantenimiento.
- Actas, cronogramas y presentaciones del proyecto.

## Convenciones

- Mantener el nombre y la versión del documento en el nombre del archivo.
- Exportar a PDF las versiones finales para consulta rápida.
- Evitar archivos temporales de Word (`~$...`).
