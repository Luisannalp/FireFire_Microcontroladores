# FireFire_Microcontroladores

Repositorio del proyecto **FireFire** (vehículo de emergencia / sistema embebido) para la asignatura de Microcontroladores del ITLA.

## Estructura del repositorio

| Carpeta | Descripción |
| --- | --- |
| `firmware/` | Código fuente del sistema embebido y proyectos de compilación. |
| `Diseño 3D/` | Modelos CAD, ensambles y archivos para impresión 3D. |
| `PCB/` | Esquemáticos, diseño de placas, Gerber y BOM. |
| `documentacion/` | Requisitos, diagramas, manuales y entregables del proyecto. |

Cada carpeta incluye un `README.md` con su propósito y las convenciones para agregar archivos.
